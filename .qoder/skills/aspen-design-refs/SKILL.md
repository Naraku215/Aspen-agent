# Aspen 设计参考（精简兜底）

designer 按需调用。你先用工程常识出第一版设计，只在拿不准时查对应节，不要整份通读。

## 1. 物性方法决策（按顺序问，第一个命中即定）

1. 体系有离子 / 电解质 / 酸碱 / 胺 / 盐？→ **ELECNRTL**
2. 有聚合物？→ **POLYNRTL**
3. 纯水 / 蒸汽体系？→ **STEAMNBS**
4. 有极性组分（醇 / 酮 / 酸 / 水 / 胺）且要算 VLE？→ **NRTL-RK / UNIQUAC / WILSON**
5. 组分非极性（轻烃 / 天然气 / 炼厂气）？→ **PENG-ROB / PR-BM / RK-SOAVE**
6. 重烃 / 原油 / 宽馏分？→ **BK10 / CHAO-SEA**
7. 以上都不是 → **PENG-ROB**（安全缺省）

**有共沸必须用活度系数模型**（NRTL-RK 系）。EOS 抓不住共沸，会给出"看似收敛但全错"的分离结果。

## 2. 常见体系速查

| 体系 | 首选方法 | 有无共沸 |
|---|---|---|
| 轻烃 C1–C5 | PENG-ROB | 无 |
| 芳烃 BTX | PENG-ROB / NRTL-RK | 无 |
| 乙醇 / 异丙醇 + 水 | NRTL-RK | **有** |
| 甲醇 + 水 | NRTL-RK | 无 |
| 电解质 / 酸碱 | ELECNRTL | — |
| 酸性水 / 胺法脱硫 | ELECNRTL | — |
| 纯水蒸汽 | STEAMNBS | — |

## 3. BIP 完备性 —— 最贵的静默错误

活度系数模型下，数据库里没有的二元对 Aspen 会**静默取 0 或用 UNIFAC 估算**，照样
"收敛"，但结果错。这比单位错更贵。

- designer 必须在 design.md 列出**关键二元对清单**（决定塔顶/塔底分离的对）
- 常见数据库自带 BIP 的对：甲醇-水、乙醇-水、丙酮-水、苯-甲苯（近理想）
- 生僻对要在 design.md 标"BIP 待核查"，让 modeler 在 S4 物性核查时确认

## 4. 可达性上限（designer 必须主动点出）

| 体系 | 常压共沸点 |
|---|---|
| 乙醇-水 | ~95.6 wt% 乙醇 |
| 异丙醇-水 | ~87.7 wt% IP |
| THF-水 | ~95 wt% THF |

甲醇-水、苯-甲苯**无共沸**，可精馏到高纯。
指标涉及分离纯度 / 转化率时，先判物理可达；不可达就在 design.md 明确标出，
别让用户建完才知道到不了。

## 5. 常识区间（定参数用）

- 常压精馏塔板数：20–60
- 回流比：1.2–5.0（最小回流比的 1.2–1.5 倍）
- 进料板：塔板数的 1/3–1/2 处
- 冷却水：25 °C 进 / 35–40 °C 出
- 低压蒸汽：3–5 bar（120–150 °C）；中压：10–15 bar（180–200 °C）

## 6. designer 阶段关键坑

- **组分标签截断**：组分名 > 8 字符会被 Aspen 截断，给预期标签
- **必含杂质 / 惰性组分行**，即使含量很低
- **压力剖面逐节点给**（工程值 + 单位，如 10 bar），防压力倒挂
- **规定选项写清楚**：填了参数还要选的选项（冷凝器/再沸器类型、PSD），别留白
- **数字规范**：数值一律“原值 + 单位”书写（如 150 C、10 bar、100 kmol/hr），
  保留原始单位，**不要换算成 SI**（modeler 按工程值 + unit 传工具换算）；
  无量纲量标注“无量纲”；流股组成基准（MOLE-FRAC / MOLE-FLOW）必须写明

## 7. 单位速查（design.md 优先工程单位，modeler 带 unit 传工具换算）

design.md 写参数优先用下表工程单位（C / bar / kmol/hr 系）；modeler 按
“工程值 + unit 参数”原样传工具，由工具换算，designer 绝不自行换算：

| 物理量 | 推荐工程单位 | design.md 可用单位（同系） |
|---|---|---|
| 温度 | C | C（K / F 需标注） |
| 压力 | bar | bar（atm / kPa / MPa 需标注） |
| 摩尔流量 | kmol/hr | kmol/hr（mol/hr 需标注） |
| 质量流量 | kg/hr | kg/hr（t/hr 需标注） |
| 功率/热负荷 | Watt | kW / MW |

**表外罕见单位**：design.md 保留原始单位并标注“罕见单位”；若工具报
`No unit conversion registered`，modeler 手工换算成 SI 值（K / Pa / kmol/s / W）
不带 unit 传入并留痕。designer 绝不自行换算。
