  逐差 48.3 / 48.9 / 49.2 / 49.1 kW）→ 与"潜热主导、显热随温度小幅上升"的物理一致，无跳变。

## 5. 结论可用性分级

### 判定：**B — 可用于方案比选**（限定范围见下）

对照 `engineering-rules.md` §7：

| 级别 | 条件 | 本 run 是否满足 |
|---|---|---|
| A 可用于设计 | 关键 BIP 已确认来自数据库/回归；严格模块；**12 条全过** | ✗ 不满足：12 条中 #12 部分不通过（液相密度）、#11 数值不可验证、#6/#10 无模型实体只能解析校核 |
| **B 可用于方案比选** | **严格模块；校核通过；但 BIP 部分为估算（需注明估算项）** | **✓ 满足**：FLASH2 是 §2.1 认定的严格模块（简化=严格同为 FLASH2）；HEATER 对"定汽化率加热"是恰当选型；12 条中的核心项（质量/元素/能量/压力/相态/规格/共沸）全部量化通过；BIP 非估算但**数值不可验证**，属同类保留 |
| C 仅趋势参考 | 用了简化模块（SEP/DSTWU/RSTOIC）**或**有未闭合项 | ✗ 两个触发条件**均不成立**：全流程无一个简化模块；无任何未闭合项（最大闭合误差 4e-9%） |
| D 未完成 | 未收敛或规格未达标 | ✗ 两块 BLKSTAT=0、规格精确命中（VFRAC 0.3000000） |

**理由（逐条引用校核项）**：

1. **比 C 高一级的依据**：§7 中 C 级的两个触发条件都不成立 —— (a) 无简化模块：
   分离单元是 FLASH2，`engineering-rules.md` §2.1 明示"闪蒸的简化模块与严格模块都是 FLASH2"，
   即**分离结果本身就是严格平衡解**（报告的 `V-L PHASE EQUILIBRIUM` 表给出真实 K 值）；
   (b) 无未闭合项：判据 #1/#2/#3 的闭合误差分别为 0.000% / 4e-9% / 0.0005%，
   比门槛好 3–8 个数量级。
2. **不能升 A 的依据**：
   - 判据 #11 未全过：BIP 的 aij/bij 数值、Tlower/Tupper **不可程序化验证**（E-BIP-1/2/3），
     "来自 APV150 VLE-RK"是三条证据联立的**推断**而非节点直接断言。
   - 判据 #12 部分不通过：液相密度偏低 **2.5–5%**（§3-2）→ 任何体积量纲结论不成立。
   - 判据 #6 / #10 只能解析校核：模型内**根本没有换热器与 utility 实体**（§3-1），
     Aspen 未算过一次 LMTD。声称"可用于设计"而设计所需的换热实体不存在，是不诚实的。
   - A-plan §11 的 **6 条工程假设**（进料 25 °C、汽化率 0.30、常压、LP 蒸汽 144 °C、
     无杂质、BIP 来源）全部**未经用户/现场数据核实**。
3. **与 A-plan / C-refine 预期的分歧（明确表态）**：A-plan「结论强度声明」与 C-refine U-4
   均自定为 **C 级**。**本阶段独立判定为 B，不同意 C。** 理由是 A-plan 定 C 时列的三条
   依据里，"BIP 来源待核对"已在 C/E 两阶段被**正面消除**（`ESTIMATE=NO` + `LBVLE=1` +
   `ENTDB=1` + `BDBANK` 含 `VLE-RK` + γ_EtOH≈3.01 的功能验证），另两条（"单级""无优化"）
   是**流程方案的范围限定，不是模型质量缺陷** —— 而 §7 的分级衡量的是模型结论的可信度，
   不是方案的雄心。硬按 C 交付会**低估**这份模型的实际可信度，进而误导下游"这些数不能用来比选"。
