## 4. 物性方法

- 方法：**NRTL-RK**（液相活度系数用 NRTL，气相逸度用 Redlich-Kwong 状态方程）
- 依据：`engineering-rules.md` §1.1 决策序列**第 4 条**（含极性组分醇+水且要算 VLE →
  NRTL-RK / UNIQUAC / WILSON），并叠加 §1.1 加粗铁律"**有共沸就必须用活度系数模型**"。
  乙醇-水常压存在约 89.4 mol%（≈95.6 wt%）乙醇的最低沸点共沸物，
  **严禁使用 PENG-ROB 等 EOS**（`pitfalls.md` B-4：EOS 会把共沸体系算成易分离、
  给出"看似收敛但完全错误"的富集结果）。
- 亨利组分 / 气相修正处理说明：
  - **无亨利组分**：本体系不含溶解性不凝气（N2/O2/CO2 等），无需指定 Henry 组分，
    NRTL 二元对已覆盖全部组分对（仅 ETHANOL/WATER 一对）。
  - **气相修正**：常压（101325 Pa）下气相接近理想，NRTL-RK 内置的 RK 方程足以修正气相逸度；
    **不需要**开启二次维里/HOC 等缔合修正（乙醇气相有轻度缔合，但在 1 atm、
    本估算精度下影响可忽略）。若 C 阶段发现气相结果异常，备选切 **UNIQUAC-RK**（见下）。
- 备选方案（若主方案结果可疑时切换）：**UNIQUAC-RK** 或 **WILSON**
  （`engineering-rules.md` §1.2 醇+水行的备选）。切换判据：气相乙醇分率算出 >89 mol%
  （越过共沸，物理不可能）→ 说明当前 BIP 有问题，先查 BIP 再考虑换方法。

### 关键二元对清单（核查下沉到 C 阶段，见 §10 步骤 3）

| 二元对 | 为什么关键 | 缺失/估算时对结论的影响 |
|---|---|---|
| **ETHANOL / WATER** | **决定全部分离结果**——气相富集程度、闪蒸温度、共沸位置全由这一对 NRTL 参数决定；且属"水+有机物"对（§1.3 最需警惕） | Aspen APV 数据库对乙醇-水的 NRTL 参数有充分回归（能复现 89.4 mol% 共沸），一般命中。**若命中的是 UNIFAC 估算值而非数据库回归值**：气相乙醇分率与闪蒸温度会偏移，结论仅可用于**趋势判断**、不可用于设计定型（本 run 目的即趋势，可接受，但必须在报告注明）。modeler 须在 C 阶段 `explore("Data\Properties\Parameters")` 核对来源标记。 |

### 可达性预判（本方案核心工程判断，必须量化）

**常压下乙醇-水存在最低沸点共沸物：约 89.4 mol% 乙醇（≈95.6 wt%），共沸温度约 78.15 °C。
这是任何基于普通气液平衡的分离（含单级闪蒸与多级精馏）无法逾越的气相富集绝对上限。**

进一步，**单级平衡闪蒸的气相富集上限远低于共沸组成**：
- 单级只提供**一个平衡级**。对进料乙醇 20.7 mol% 的料液，与之平衡的气相组成
  沿常压乙醇-水 VLE 曲线取值。汽化率越低（越接近泡点），气相越富，其**理论上确**
  出现在 VFRAC→0（泡点）时，约 **53 mol% 乙醇（≈74 wt%）**。
- 在有实际气相量的工况（VFRAC=0.10~0.50）下，气相乙醇约 **38–50 mol%（≈61–71 wt%）**；
  基准 VFRAC=0.30 约 **44 mol%（≈67 wt%）**。
- **为什么远低于共沸的 89.4 mol%**：要把气相推近共沸组成，需要**多个平衡级的逐级精馏**
  （精馏塔）不断把气相再冷凝-再蒸发提浓；单级闪蒸只做**一次**汽液接触，物理上够不到。
  故本方案能明确回答用户："单级闪蒸气相乙醇最多富集到约 50 mol%（74 wt%）出头量级，
  想更高必须上精馏塔——而即便上塔，常压普通精馏也止步于 ~89 mol% 共沸点。"
  用户已明确排除塔，故本 run 交付的即为**单级闪蒸能达到的富集程度上限量级**。
