## 第一部分：碳捕集（Carbon Capture）

### 1. 概览

Aspen Plus V15.0 的 Carbon Capture 分类共包含 43 个示例流程，覆盖了当前主流的碳捕集技术路线：

- 化学吸收法（胺法）：MEA、DEA、MDEA、DGA、DIPA、TEA、AMP、PZ、K₂CO₃、NH₃、NaOH 及混合溶剂
- 物理溶剂法：DEPG（Selexol）、NMP、碳酸丙烯酯（Propylene Carbonate）、甲醇（Rectisol）
- 膜分离法：ACM 交叉流膜模型
- 电化学还原法：固体氧化物电解池（SOEC）
- CO₂ 压缩与纯化（Conditioning）

### 2. 化学吸收法——胺溶剂体系

#### 2.1 物性方法

所有胺法 CO₂ 捕集流程统一采用 **ELECNRTL**（Electrolyte Non-Random Two Liquid）物性方法，部分变体使用 **ENRTL-RK**（气相用 Redlich-Kwong 状态方程）。

ELECNRTL 支持的完整组分列表（16 个）包括：

| 序号 | 组分 | 类型 |
|------|------|------|
| 1 | CO₂ | 溶解气体 |
| 2 | H₂O | 溶剂 |
| 3 | MEA / DEA / MDEA / DGA / DIPA / TEA | 胺（按具体流程选择） |
| 4 | H⁺ | 阳离子 |
| 5 | OH⁻ | 阴离子 |
| 6 | HCO₃⁻ | 阴离子 |
| 7 | CO₃²⁻ | 阴离子 |
| 8 | RNH₃⁺ / R₂NH₂⁺ / R₃NH⁺ | 质子化胺阳离子 |
| 9 | RNHCOO⁻ / R₂NCOO⁻ | 氨基甲酸酯阴离子 |
| 10 | N₂ / O₂ | 烟气惰性组分 |

液相非理想性由 e-NRTL 模型描述，气相由 Redlich-Kwong EOS 描述。

#### 2.2 溶液化学反应

以通用伯胺 RNH₂ 为例，CO₂ 吸收过程中的溶液化学包含以下反应：

**电离平衡（快速）：**

```
2H₂O ⇌ H₃O⁺ + OH⁻                                    (1) 水自电离
CO₂ + 2H₂O ⇌ HCO₃⁻ + H₃O⁺                            (2) CO₂水解
HCO₃⁻ + H₂O ⇌ CO₃²⁻ + H₃O⁺                           (3) 碳酸氢根解离
RNH₃⁺ + H₂O ⇌ RNH₂ + H₃O⁺                             (4) 质子化胺解离
```

**化学平衡/动力学反应：**

```
RNH₂ + HCO₃⁻ ⇌ RNHCOO⁻ + H₂O                          (5) 氨基甲酸酯生成
```

对于伯胺和仲胺，反应 (5) 是 CO₂ 与胺直接反应生成氨基甲酸酯的关键步骤。叔胺（如 MDEA）不能直接生成氨基甲酸酯，仅通过水解反应 (2) 间接吸收 CO₂，因此反应速率较慢但再生能耗更低。

#### 2.3 动力学反应

受动力学控制的反应及其速率表达式：

```
CO₂ + OH⁻ → HCO₃⁻                                     (10)
HCO₃⁻ → CO₂ + OH⁻                                     (11)
RNH₂ + CO₂ + H₂O → RNHCOO⁻ + H₃O⁺                    (12) 正向
RNHCOO⁻ + H₃O⁺ → RNH₂ + CO₂ + H₂O                     (13) 逆向
```

速率计算采用幂律表达式，以活度为浓度基准：

```
r = k × exp(-E/RT) × ∏(aᵢ)^nᵢ
```

其中 r 为反应速率，k 为指前因子，E 为活化能，T 为系统温度，R 为气体常数，aᵢ 为组分 i 的活度，nᵢ 为组分 i 的反应级数。

正向反应动力学参数来自文献，逆向反应参数通过化学平衡约束调优获得。

#### 2.4 各胺溶剂流程详情

##### 2.4.1 MEA（单乙醇胺）

- **溶剂浓度**：15-30 wt% MEA（典型值 30 wt%）
- **吸收塔**：Rate-based 模型，20 块理论板，MELLAPAK 250Y 规整填料
- **再生塔**：Rate-based 模型，20 块理论板
- **典型操作条件**：
  - 吸收塔：40-60°C，1-2 bar
  - 再生塔：120°C（塔釜），1.5-2 bar
- **CO₂ 去除率**：85-95%
- **比再沸器能耗**：3.5-4.2 MJ/kg CO₂
- **应用场景**：最成熟的一代胺法技术，基准对比方案

##### 2.4.2 DEA（二乙醇胺）

- **溶剂浓度**：20-35 wt% DEA
- **特点**：与 MEA 相比蒸汽压更低，溶剂损失小；但分子量更大，CO₂ 载荷略低
- **再生能耗**：略低于 MEA（~3.3-3.8 MJ/kg CO₂）

##### 2.4.3 MDEA（甲基二乙醇胺）

- **溶剂浓度**：30-50 wt% MDEA
- **特点**：叔胺，不能直接生成氨基甲酸酯；选择性吸收 H₂S 优于 CO₂；再生能耗最低
- **再生能耗**：2.5-3.0 MJ/kg CO₂
- **应用**：常用于选择性脱硫场景

##### 2.4.4 DGA（二甘醇胺）

- **溶剂浓度**：50-60 wt% DGA（可高浓度运行）
- **特点**：同时含有胺基和醚基，CO₂ 吸收容量大；适用于高 CO₂ 分压场景
- **再生能耗**：3.0-3.5 MJ/kg CO₂

##### 2.4.5 DIPA（二异丙醇胺）

- **溶剂浓度**：30-40 wt% DIPA
- **特点**：空间位阻效应，兼具伯胺高吸收速率和叔胺低再生能耗的优点
- **再生能耗**：2.8-3.3 MJ/kg CO₂

##### 2.4.6 TEA（三乙醇胺）

- **溶剂浓度**：15-30 wt% TEA
- **特点**：叔胺，与 MDEA 类似但分子量更大
- **再生能耗**：3.0-3.5 MJ/kg CO₂

##### 2.4.7 AMP（2-氨基-2-甲基-1-丙醇）

- **溶剂浓度**：20-30 wt% AMP
- **特点**：空间位阻胺，生成的氨基甲酸酯不稳定，易水解为碳酸氢盐；因此兼具高吸收速率和低再生能耗
- **再生能耗**：2.8-3.2 MJ/kg CO₂

##### 2.4.8 PZ（哌嗪）

- **溶剂浓度**：5-15 wt% PZ
- **特点**：环状仲胺，反应速率极快（比 MEA 快 5-10 倍）；CO₂ 容量高；常作为活化剂与其他胺混合使用
- **再生能耗**：3.0-3.5 MJ/kg CO₂

##### 2.4.9 K₂CO₃（碳酸钾）

- **溶剂浓度**：20-30 wt% K₂CO₃
- **特点**：无机碱，热稳定性极好；反应速率较慢，通常需要添加活化剂（如 PZ 或 MEA）
- **再生能耗**：2.0-2.5 MJ/kg CO₂（最低之一）
- **应用**：高温 CO₂ 脱除（Benfield 工艺）

##### 2.4.10 NH₃（氨水）

- **溶剂浓度**：5-15 wt% NH₃
- **特点**：再生能耗低，但氨挥发问题严重；需水洗段控制氨逃逸
- **再生能耗**：2.5-3.0 MJ/kg CO₂

##### 2.4.11 NaOH（氢氧化钠）

- **溶剂浓度**：5-10 wt% NaOH
- **特点**：强碱，不可再生（一次性使用）；仅用于特殊场景
- **应用**：小规模或应急 CO₂ 脱除

#### 2.6 物理溶剂法

##### 2.6.1 DEPG（Selexol / 聚乙二醇二甲醚）

- **物性方法**：Peng-Robinson
- **溶剂**：Dimethyl ethers of polyethylene glycols (DEPG)
- **特点**：物理吸收，高压下 CO₂ 溶解度大；再生通过闪蒸实现，无需加热
- **应用**：高 CO₂ 分压的天然气处理、IGCC 预燃烧捕集
- **操作压力**：20-70 bar
- **再生能耗**：1.5-2.5 MJ/kg CO₂（显著低于化学吸收）

##### 2.6.2 NMP（N-甲基吡咯烷酮）

- **物性方法**：Peng-Robinson
- **特点**：优良的热稳定性和化学稳定性；对 CO₂ 选择性较好
- **应用**：天然气脱碳、合成气净化

##### 2.6.3 碳酸丙烯酯（Propylene Carbonate）

- **物性方法**：Peng-Robinson
- **特点**：物理溶剂，高沸点，低蒸汽压
- **应用**：高压天然气脱碳

##### 2.6.4 甲醇（Rectisol 工艺）

- **物性方法**：Peng-Robinson
- **操作温度**：-30 至 -60°C（低温物理吸收）
- **特点**：同时脱除 CO₂、H₂S、COS 等酸性气体；净化度极高
- **应用**：煤化工、IGCC 整体煤气化联合循环

#### 2.7 膜分离法

- **模型类型**：ACM（Aspen Custom Modeler）交叉流膜组件模型
- **传质机理**：溶解-扩散模型
- **膜材料**：聚合物中空纤维膜
- **驱动力**：跨膜分压差
- **应用**：烟气 CO₂ 捕集、天然气脱碳
- **特点**：设备紧凑、无运动部件；但单级分离因子有限，通常需要多级配置

#### 2.8 电化学 CO₂ 还原（SOEC）——详细案例

##### 2.8.1 技术背景

固体氧化物电解池（SOEC）利用可再生电力将 CO₂ 电化学还原为 CO，CO 可作为合成气组分用于费托合成、甲醇合成等。

**电化学反应：**
```
阴极：CO₂ + 2e⁻ → CO + O²⁻
阳极：O²⁻ → ½O₂ + 2e⁻
总反应：CO₂ → CO + ½O₂
```

##### 2.8.2 ACM 模型描述

**基本假设：**
1. 稳态操作
2. 理想气体行为
3. 均匀恒定的操作温度
4. 完全电化学反应
5. 固体电解质无漏电
6. 电极界面浓度等于主体流道浓度

**电压组成：**
```
V_applied = E_Nernst + η_ohm + η_act,c + η_act,a + η_conc,c + η_conc,a
```

**Nernst 电位：**
```
E_Nernst = E⁰ + (RT/2F) × ln(p_CO × p_O₂^0.5 / p_CO₂)
E⁰ = ΔG⁰ / 2F
```

其中 ΔG⁰ 通过 ACM 调用函数计算纯组分的标准 Gibbs 自由能。

**物性方法**：Soave-Redlich-Kwong (SRK) 状态方程，利用其内聚函数计算高温行为：
```
a(T) = a_c × [1 + ω(1 - √(T/T_c))]²
```

**欧姆过电位（仅考虑电解质）：**
```
η_ohm = J × L × 10,300 × exp(2.99×10⁴ / T)
```
其中 J 为电流密度，L 为电解质厚度。

**活化过电位（Butler-Volmer 方程）：**
```
i = i₀ × [exp(αnFη_act/RT) - exp(-(1-α)nFη_act/RT)]
η_act = (RT/nF) × asinh(i / 2i₀)
```

**浓差过电位：**
```
η_conc,c = (RT/2F) × ln[(1 + i/i_L,c) / (1 - i/i_L,c)]
η_conc,a = (RT/4F) × ln[(p_O₂,bulk + i×RT/4F×δ_a/D_eff) / p_O₂,bulk]
```

**CO 产量（法拉第定律）：**
```
ṅ_CO = N_cells × A_cell × i / 2F
P = N_cells × A_cell × V × i
```

##### 2.8.4 多变量分析

温度（500-1050°C）和功率（50-1000 kW）对 CO₂ 转化率和单位 CO 功耗的影响：
- 高温 → 低单位 CO 功耗，但需额外热量维持温度
- 存在温度-功率-产量之间的权衡关系

### 1. 概览

#### 5.2 Case 2 模拟详情

### 6. SOFC-CHHP（固体氧化物燃料电池热电氢联产）——详细案例

#### 6.1 技术背景

1 MW 甲烷燃料 SOFC 联合热、氢、电（CHHP）系统，稳态模拟。零维直接内部重整 SOFC（DIR-SOFC）模型在 ACM 中创建并集成到 Aspen Plus。

#### 6.2 工艺流程

**燃料侧：**
- 甲烷压缩后与阳极循环气（ recycle ratio ≈ 0.65）混合
- HX-01 预热至 700°C 进行预重整（20% 甲烷转化）
- HX-02 由阳极循环气进一步加热至约 650°C 进入阳极通道

**空气侧：**
- 空气由 O₂/电化学反应 O₂ 比约 3.3 确定流量（限制温升约 150°C）
- HX-03 部分预热至约 80°C（同时冷却阳极尾气至 300°C 利于 WGS 反应）
- HX-04 由阴极排气进一步加热至约 650°C

**SOFC 模型（ACM）：**
- 阳极反应：
  ```
  CH₄ + H₂O ↔ CO + 3H₂      (蒸汽重整)
  CO + H₂O ↔ CO₂ + H₂       (水煤气变换)
  H₂ + ½O₂ → H₂O             (电化学反应)
  ```
- 假设：所有甲烷完全重整；CO 不能直接电化学氧化，仅通过 WGS 转化为 H₂

**尾气处理：**
- 未循环阳极尾气 → WGS 反应器（达到平衡）
- WGS 出口气 → 冷却 → EHS（电化学氢分离）回收 85% H₂
- 回收的 H₂ 压缩至 30 bar 储存
- EHS 尾气 + 部分阴极排气 → 燃烧器 → 余热回收

#### 6.3 电化学模型

**极化曲线：**
```
V_cell = OCV - η_act - η_ohm - η_conc
```

**开路电压（Nernst 方程）：**
```
OCV = E_nernst + (RT/2F) × ln(p_H₂ × p_O₂^0.5 / p_H₂O) × (1/p_atm^0.5)
E_nernst = 1.2723 - 2.7645×10⁻⁴ × T
```
引入经验系数 θ = 0.94 修正 Nernst 方程与实验值的偏差。

**活化极化（Butler-Volmer）：**
```
i = i₀ × [exp(αnFη_act/RT) - exp(-(1-α)nFη_act/RT)]
```

阳极交换电流密度：
```
i₀,a = γ_a × (p_H₂/p_atm) × (p_H₂O/p_atm)^(-1) × exp(-E_act,a/RT)
```

阴极交换电流密度：
```
i₀,c = γ_c × (p_O₂/p_atm)^0.25 × exp(-E_act,c/RT)
```

**欧姆损失：**
```
η_ohm = i × ASR_ohm
```

**浓差损失：**
```
η_conc = (RT/nF) × ln(i_L / (i_L - i))
```
极限电流密度 i_L = 1.6 A/cm²。

**总 DC 功率：**
```
P_DC = i × A_cell × V_cell × N_cell
```

#### 6.4 效率定义

所有效率基于甲烷低热值（LHV）：

```
η_CHHP_total = (P_net + Heat + ṁ_H₂ × LHV_H₂) / (ṁ_CH₄ × LHV_CH₄)
η_elec = P_net / (ṁ_CH₄ × LHV_CH₄)
η_heat = Heat / (ṁ_CH₄ × LHV_CH₄)
η_H₂ = (ṁ_H₂ × LHV_H₂) / (ṁ_CH₄ × LHV_CH₄)
```

### 7. PEM 燃料电池——详细案例

#### 7.1 技术背景

#### 7.2 ACM 模型方程

基于 Yi 和 Nguyen 的沿流道模型。

**阳极质量平衡：**
```
∂M_H₂/∂x = -βhI/2F
∂M_H₂O^L/∂x = (M_H₂O^L × βk/hd) × (P_pa^c - P_a) × [R(T+273.15)]^(-1) × P_H₂O^sat
∂M_H₂O^V/∂x = -M_H₂O^L × 3600hα(x) × 1E4I/F
(Cp × ∂T/∂x) × (M_H₂ + M_H₂O^V + M_H₂O^L) / 1E3 = U_h(T_s - T_a)
```

**阴极质量/能量平衡：** 类似表达式。

**固体层能量平衡：**
```
3.6A_sol × k_s × ∂²T_s/∂x² - ... = 复杂热传导方程
```

**电流密度与功率：**
```
I_avg = (1/L) × Σ(∂I/∂x)
I(x) = cond_m(x) × (V_oc - V_cell(x) - V_overc(x))
V_stack = V_cell × N_cell
Power = I_avg × V_stack × N_cell × h × L_c
```

**膜电导率：**
```
cond_m(x) = (0.005139 × wc_a(x) - 0.00326) × exp(1268 × (1/303 - 1/(273.15+T_s(x))))
```

**水传递：**
```
α(x)×I(x) = n_d(x)×I(x) - F×D_w(x) × (wc_c(x)-wc_a(x))/1E5t_m - (P_pc_H₂O(x) - P_pa_H₂O(x))×1E5 / [2×(0.001×Visc_W)×100t_m]
```

### 3. 关键发现

1. **胺法碳捕集**：ELECNRTL 是标准物性方法；CESAR1（AMP+PZ）作为第二代溶剂在中试规模验证了 rate-based 模型的预测能力；比再沸器能耗 3.4-4.9 MJ/kg CO₂ 取决于操作条件。

2. **物理溶剂**：在高压场景下具有显著的能耗优势（1.5-2.5 MJ/kg CO₂），但需要高压操作条件。

3. **电化学路线**：SOEC 还原 CO₂ 为 CO 可实现净负排放（使用可再生电力时），总成本约 $661/tonne CO；电力来源是决定经济性和环境效益的关键因素。

4. **CO₂ 纯化压缩**：CPA 状态方程适用于 CO₂ 压缩纯化全流程；TEG 脱水可将水含量降至 48 ppm；最终 CO₂ 纯度 99.94% 满足管道运输标准。

5. **SOFC-CHHP**：甲烷燃料电池热电氢联产系统总效率高达 85.3%（LHV 基准），电效率 48.8%，同时产出压缩氢（30 bar）和热水（80°C）。模拟结果与文献值高度吻合。

6. **氢液化**：SMR 和 CMR 两种方案均可实现 165 吨/天液化能力；正-仲氢转化必须在液化过程中建模。

7. **海上制氢**：风电-RO-PEM 集成系统展示了海上可再生能源制氢的可行性，10 MW 风机可支持约 150 kg/h 产氢量。
