# 工程判据库 — engineering-rules

面向 `aspen-designer`（选物性、定拓扑、定参数）与 `aspen-checker`（校核判据）。
这里是**工程决策依据**，不是工具用法。工具用法看 `mcp-playbook.md`。

---

## 1. 物性方法决策

### 1.1 决策序列（按顺序问，第一个命中即定）

```
1  体系里有离子 / 电解质 / 酸碱 / 胺 / 盐？        → ELECNRTL（或 OLI-ES）
2  有聚合物？                                     → POLYNRTL / POLYUFV
3  纯水/蒸汽体系？                                → STEAMNBS / IAPWS-95
4  有极性组分（醇、酮、酸、水、胺）且要算 VLE？   → NRTL-RK / UNIQUAC / WILSON
5  压力 > 10 bar 且组分非极性？                   → PENG-ROB / PR-BM / RK-SOAVE
6  重烃、原油、宽馏分？                           → BK10 / CHAO-SEA / GRAYSON
7  以上都不是                                     → PENG-ROB（安全缺省）
```

**有共沸就必须用活度系数模型**（NRTL-RK 系），EOS 抓不住共沸。
乙醇-水、异丙醇-水、THF-水 这类体系用 PENG-ROB 会给出**看似收敛但完全错误**的分离结果。

### 1.2 常见体系速查

| 体系 | 首选 | 备选 | 备注 |
|---|---|---|---|
| 轻烃 C1–C5 | PENG-ROB | PR-BM, RK-SOAVE | 立方 EOS |
| 重烃 / 原油 | BK10 | CHAO-SEA, GRAYSON | 宽馏分 |
| 芳烃 BTX | PENG-ROB | NRTL-RK | 中压 |
| 醇 + 水 | NRTL-RK | UNIQUAC, WILSON | 有共沸 |
| 共沸体系 | NRTL-RK | UNIQUAC-RK | 必须活度系数 |
| 电解质 / 酸碱 | ELECNRTL | OLI-ES | 需生成离子组分 |
| 酸性水 / 胺法脱硫 | ELECNRTL | — | H2S/CO2/NH3 in H2O |
| 高压 CO2 捕集 | PSRK / ELECNRTL | PR-BM | 视是否含胺 |
| 纯水蒸汽 | STEAMNBS | IAPWS-95 | 动力/换热用 |
| 深冷 | PENG-ROB | PR-BM | 低温气体 |
| 聚合物 | POLYNRTL | POLYUFV | 需聚合物数据库组分 |
| 水合物抑制剂（MEG/MeOH） | PSRK | PENG-ROB | — |

### 1.3 二元交互参数（BIP）完备性 —— 最贵的静默错误

用活度系数模型（NRTL/UNIQUAC/WILSON）时，Aspen 对**数据库里没有的二元对**会
**静默取 0 或用 UNIFAC 估算**，然后照样"收敛"。结果是错的，但所有状态位都是绿的。
这比单位错更贵 —— 单位错至少通常会炸出 FEED FLASH FAILURE。

**A 阶段必做**：designer 在 `A-plan.md` 中列出**关键二元对清单**，判据是：

- 该二元对是否决定关键分离（塔顶/塔底组分之间的对）
- 该二元对是否涉及水与有机物（最常缺）
- 该二元对是否涉及新引入的溶剂/夹带剂

**B 阶段必做**：modeler 尝试 `explore("Data\Properties\Parameters")` 核对。
读不全时**必须**在 `B-skeleton.md` 中写明：

```
BIP 核查结果：程序化读取不完整
关键二元对：ETHANOL/WATER（决定塔顶纯度）、ETHANOL/N2（惰性，影响小）
未确认项：ETHANOL/WATER 的 NRTL 参数来源（数据库 vs UNIFAC 估算）
影响判断：若为 UNIFAC 估算，塔顶乙醇纯度结果不可用于设计定型，只可用于趋势判断
建议：人工在 GUI → Methods → Parameters → Binary Interaction 核对来源标记
```

沉默略过 BIP 检查是不可接受的。

## 2. 模块选型判据

### 2.1 分离

| 场景 | 简化模块（B 阶段） | 严格模块（C 阶段） |
|---|---|---|
| 精馏 | SEP（给分割率）或 DSTWU（短切） | RADFRAC |
| 闪蒸/汽液分离 | FLASH2 | FLASH2（本身即严格） |
| 三相分离 | FLASH3 / DECANTER | FLASH3 / DECANTER |
| 萃取 | SEP | EXTRACT |
| 吸收 | SEP | RADFRAC（无冷凝器无再沸器） |

**DSTWU 的正确定位**：它是**短切设计工具**，用来估最小回流比、最小塔板数、
合理塔板数与进料位置，然后把结果**当 RADFRAC 的初始规格**。不要把 DSTWU 当最终模型交付。

### 2.2 反应

| 已知条件 | 选型 |
|---|---|
| 只知转化率 | RSTOIC |
| 只知产物收率分布（裂解、气化） | RYIELD |
| 反应达平衡，已知反应式 | REQUIL |
| 反应达平衡，产物未知/体系复杂 | RGIBBS |
| 有动力学数据 + 全混釜 | RCSTR |
| 有动力学数据 + 管式 | RPLUG |

**建模顺序**：先用 RSTOIC / RYIELD 跑通全局物料能量平衡，
确认反应器进出口物流合理后，再换成 RCSTR / RPLUG。
一上手就上动力学反应器，收敛失败时无法区分是动力学参数错还是流程结构错。

### 2.3 换热

- 只需定温/定负荷、不关心设备 → HEATER
- 需要两股物流耦合、算 UA/LMTD → HEATX
- 多股耦合 → MHEATX（**注意：无 MCP 文档，需 fallback 探节点**）

## 3. 界区与公用工程条件（模糊需求最常缺的部分）

designer 在信息不足时**用下表缺省值 + 在 A-plan 中标注"假设"**，
不要停下来问这些（问也要带推荐值）。

| 项 | 常用缺省 |
|---|---|
| 低压蒸汽 LP | 0.4 MPa(a) / ~144 °C |
| 中压蒸汽 MP | 1.0 MPa(a) / ~180 °C |
| 高压蒸汽 HP | 4.0 MPa(a) / ~250 °C（过热则另注） |
| 循环冷却水 CW | 供 32 °C / 回 42 °C |
| 冷冻水 | 供 7 °C / 回 12 °C |
| 低温冷剂 | −25 °C 级 / −40 °C 级 |
| 换热最小温差 ΔTmin | 气-气 20 K；液-液 10 K；有相变 5–10 K |
| 塔压 | 常压塔顶 0.10–0.12 MPa(a)；真空塔视热敏性定 |
| 单板压降 | 板式 0.5–0.7 kPa/板；填料 0.2–0.4 kPa/m |
| 泵出口余量 | 满足下游 + 0.05–0.1 MPa 控制阀压降 |
| 塔底温度上限 | 受热敏性/结垢约束，需与再沸器蒸汽温位匹配（ΔT ≥ 15 K） |

## 4. E 阶段校核清单（判据与阈值）

`BLKSTAT = 0` 只是入场券，不是通过条件。checker 必须逐条走完并给出**量化结果**，
不允许写"看起来正常"。

| # | 检查项 | 判据 | 不通过的典型病因 |
|---|---|---|---|
| 1 | 总质量平衡 | Σ入 − Σ出 闭合 ≤ ±0.5% | 循环未真收敛、有物流未连 |
| 2 | 元素平衡（有反应时） | 每种元素闭合 ≤ ±0.5% | 反应式配平错、化学计量输错 |
| 3 | 能量平衡 | Σ热流闭合，无凭空的巨大 duty | 模块规格互相矛盾 |
| 4 | 产品规格 vs 目标 | 逐项列"目标 / 实际 / 差距%" | 规格不可达、调参未收口 |
| 5 | 压力剖面单调 | 沿流程无倒挂（下游压力 > 上游且中间无泵/压缩机） | MIXER 取最低入口压、忘设压降 |
| 6 | 换热器温差 | 无温度交叉，LMTD > 0 且 ≥ ΔTmin | 冷热流搞反、负荷给过大 |
| 7 | 塔水力 | 无干板（COLUMN DRIES UP）、无淹塔；气液负荷合理 | 规格过严、塔板数/进料位置不当 |
| 8 | 相态符合设计意图 | 泵入口全液（VFRAC=0）、压缩机入口全气（VFRAC=1）、塔顶相态与冷凝器类型一致 | 温压组合选错 |
| 9 | 循环回路组分累积 | 惰性/微量组分在循环中的摩尔分数**有界**，不随迭代单调上升 | 无排放口（purge）、分离效率设成 100% |
| 10 | 公用工程温位匹配 | 加热介质温度 > 被加热物流出口 + ΔTmin；冷却同理 | 用 CW 冷到 30 °C 以下等物理不可能 |
| 11 | BIP 缺口对结论的影响 | 明确写"结论可用于 定型 / 仅趋势" | 见 §1.3 |
| 12 | 与工程常识的矛盾 | 塔回流比、单位能耗、设备尺寸落在常识区间 | 见 §5 |

任一条不通过 → checker 返回 `DONE_WITH_CONCERNS` 并量化，**不得放宽判据**。

## 5. 工程常识区间（用于第 12 条"闻起来对不对"）

| 量 | 常识区间 | 超出说明 |
|---|---|---|
| 精馏回流比 R | 0.5–10（多数 1–5） | R > 20 通常意味着分离要求不合理或物性错 |
| R / Rmin | 1.1–1.5 | < 1.05 塔板数爆炸；> 2 能耗浪费 |
| 塔板数 | 10–60（普通分离）；> 60 见于近沸点/共沸体系 | 需要 100+ 板先怀疑物性方法 |
| 塔板效率 | 板式 0.5–0.8 | — |
| 精馏能耗 | 0.5–2 t 蒸汽 / t 产品（视相对挥发度） | 数量级偏离先查物性 |
| 相对挥发度 α | > 1.5 易分；1.1–1.5 难分；< 1.05 需特殊精馏 | α ≈ 1 说明该体系不能用普通精馏，方案要改 |
| 泵扬程 | 一般 < 200 m（单级离心） | — |
| 压缩机单级压比 | 2.5–4 | 更高需多级 + 级间冷却（MCOMPR） |
| 换热器 U 值 | 气-气 20–60；液-液 300–1000；冷凝 800–2000 W/m²K | — |
| 反应器停留时间 | 液相 CSTR 分钟–小时；气相 PFR 秒–分钟 | — |

## 6. 常见 Aspen 报错 → 工程含义

| 报错 | 真实含义 | 处理方向 |
|---|---|---|
| FEED FLASH FAILURE | 进料闪蒸算不出来 | 首查 T/P 是否 SI；再查组成是否全零；再查物性方法适用性 |
| BLKSTAT = 2 | 未收敛 | 按 pitfalls 的分层排障，先给初值再改规格 |
| BLKSTAT = 3 | 输入错误 | 读 BLKMSG 原文，`find_incomplete_inputs()` |
| COLUMN DRIES UP | 某级无液相 | 规格过严 / 进料级不当 / 塔压与进料压不匹配 |
| DID NOT CONVERGE IN N ITERATIONS | 迭代上限 | 给更好初值；简化后逐步复杂化 |
| FLASH SPECIFICATION INCONSISTENT | 两个闪蒸规格矛盾 | 如 TEMP + VFRAC 物理上不共存 |
| ZERO FLOW IN STREAM | 流股无流量 | 组成或总流量未设 / 分割率给成 0 |
| PHYSICAL PROPERTY ERROR | 物性模型算不出 | 物性方法与体系不匹配，或组分缺参数 |
| WEGSTEIN DIVERGENCE | 循环求解发散 | tear 初值差、回路内规格互锁 |
| STREAM NOT CONNECTED | 流股未接端口 | `connect_port()` |
| INVALID UNIT SET | 单位集名错 | 只用 SI / METCBAR / ENG |

## 7. 结论的可用性分级（写进 REPORT.md）

系统必须自评结论强度，不允许把趋势性结果说成设计定型值。

| 级别 | 含义 | 条件 |
|---|---|---|
| **A 可用于设计** | 关键 BIP 已确认来自数据库/回归；严格模块；校核 12 条全过 | — |
| **B 可用于方案比选** | 严格模块；校核通过；但 BIP 部分为估算 | 需注明估算项 |
| **C 仅趋势参考** | 用了简化模块（SEP/DSTWU/RSTOIC）或有未闭合项 | 需注明简化处 |
| **D 未完成** | 未收敛或规格未达标 | 必须出 `HANDOVER.md` |
